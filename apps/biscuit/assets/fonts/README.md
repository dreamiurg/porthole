# Montserrat

Unmodified Montserrat Regular and SemiBold TrueType fonts, from the typeface's
[official repository](https://github.com/JulietaUla/Montserrat), pinned to commit
`555facfb2a18c72c3c0380f0d9c0f060453a9058`.

- [Regular source](https://github.com/JulietaUla/Montserrat/blob/555facfb2a18c72c3c0380f0d9c0f060453a9058/fonts/ttf/Montserrat-Regular.ttf)
- [SemiBold source](https://github.com/JulietaUla/Montserrat/blob/555facfb2a18c72c3c0380f0d9c0f060453a9058/fonts/ttf/Montserrat-SemiBold.ttf)
- License: SIL Open Font License 1.1; full text in [OFL.txt](OFL.txt).

The browser serves these files locally; gameplay makes no font network requests.
Montserrat is also the family used by LVGL's built-in fonts. These TTF sources
can be converted to selected sizes and glyphs for LVGL; the browser renderer is
not an exact reproduction of LVGL's glyph rasterization or hardware performance.
