# Chaos from home: an adopted pup, then 600 random gestures per seed (taps, double taps, drags, slow taps,
# long presses). Runs under ASan/UBSan; after each run the game must be on a real screen with stats in 0..100.
# seed 101: a plain home
newgame Sam Biscuit
wait 2000
expect-screen home
monkey 600 101
expect-screen *
expect food>=0
expect food<=100
expect fun>=0
expect fun<=100
expect energy>=0
expect energy<=100
expect clean>=0
expect clean<=100
# seed 202: a busy home: muddy pup, poop, a gift waiting
newgame Sam Biscuit
wait 2000
dbg dirty
dbg poop
skip 86400
wait 200
expect gift=1
monkey 600 202
expect-screen *
expect food>=0
expect food<=100
expect fun>=0
expect fun<=100
expect energy>=0
expect energy<=100
expect clean>=0
expect clean<=100
