# Rally's top levels on Desert Canyon (top 14, Pro hazards at 12-14): a loss from the top steps down three a race
# (14 -> 11 -> 8 -> 5 -> 2, then 0 like any loss from 1..3), so losing at the top takes several races to fall to 0; a
# win at the top stays at the top.
# Finishes come from the dbg fixtures (reachability), so this is a regression check, not evidence of how a race feels;
# the black-box pass is docs/racing/pro-playtest/README.md.
reset
tilt 0 1000 0
profile Zoe 10
app racing
wait 600
expect level=0
dbg lastlap
wait 5500
expect-screen race_results
dbg level 14
# a win at the top stays at the top
tap 52 111
wait 4000
expect race_level=14
dbg lastlap
wait 5500
expect place=1
expect level=14
# five losses in a row: 14 -> 11 -> 8 -> 5 -> 2 -> 0
tap 52 111
wait 4000
dbg lastplace
wait 5500
expect-screen race_results
expect place=4
expect level=11
tap 52 111
wait 4000
dbg lastplace
wait 5500
expect level=8
tap 52 111
wait 4000
dbg lastplace
wait 5500
expect level=5
tap 52 111
wait 4000
dbg lastplace
wait 5500
expect level=2
tap 52 111
wait 4000
dbg lastplace
wait 5500
expect level=0
