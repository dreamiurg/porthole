# Rally art provenance

Every picture in `apps/porthole/games/racing/art/` was generated by Codex CLI 0.160's built-in image tool on 2026-10-31,
with both approved reference boards attached to every request (`docs/superpowers/specs/porthole-racing/assets/reference/`
`generated-image.png` and `level-showcase-upload.png`). The originals were downscaled with nearest-neighbor to at most
256 px (960 px for skylines) before committing; `apps/porthole/games/racing/tools/pictures.py` converts them to
`pictures.h` and `skyline0-3.h`. Rivals are the player's car with the body hue turned by the generator.

Command (one per asset, run in an empty directory):

```bash
codex exec --skip-git-repo-check --ephemeral -C <dir> -s workspace-write -i generated-image.png -i level-showcase-upload.png -- "<prompt>" < /dev/null
```

Shared prompt, with `KEY` and `ASSET` filled in per row below:

> The two attached images are the APPROVED style references for our game. Match their art style exactly: the bottom row 'Style 2 - Rugged Action Arcade' panels 2A-2D of the first image, and the four track scenes in the top row of the second image (same pixel-art rendering, palette, lighting, outline weight, level of detail). Use your built-in image generation tool to create ONE new standalone asset in that exact style, then copy the resulting PNG into the current directory as a.png. Do nothing else. The asset: ASSET Pixel art with crisp square pixels, no anti-aliasing, no text, no letters, no logos, no UI, no ground shadow. The background must be one perfectly flat solid color #KEY everywhere outside the subject (for wide scenery: the whole sky is flat #KEY), no gradient, no texture. Do not use #KEY or any close color inside the subject. Square image. (Skylines: Very wide panoramic image, 3:1 aspect ratio.)
