# Generic manual content and review rules

## Page and sequence decisions

- Sort parts and tools before assembly and show the current design/source basis where it affects the step.
- Show end faces, slots, holes, and tool access whenever they determine the fastener or tap direction; do not use a misleading shortened side view.
- Begin each subsystem with its datum and orientation, then add one representative joint detail and a mirror/repeat note only when both sides are identical.
- Define fixed, floating, locating, clamping, and temporary supports in both the drawing and prose when those roles matter.
- Keep long-span dimensions tied to the active design source; never revive a remembered value without a revision check.

## Review lessons

- Test comments are useful for validating extraction but do not belong in the final PDF.
- If a page overflows, shorten prose or simplify the diagram before shrinking all typography.
- Use text/labels to explain hidden geometry; do not let color or translucency carry critical meaning alone.
- Review legibility at the printed/page size, not just a zoomed editor view.
