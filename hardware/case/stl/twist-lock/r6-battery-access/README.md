# P021 battery access plate

**For an existing twist-lock puck, print one [P021 middle plate for Bambu Studio](bambu/P021-plate.3mf).** The U-shaped opening extends 8.7 mm farther along the battery lead. It is 19.7 mm long overall and 12 mm wide at the connector. Transfer the original plate screws.

The Bambu project places the broad board-facing side on the bed, with the three posts pointing up. Use the same orientation for the [standalone plate STL](P021-plate.stl). The recessed P021 mark faces the battery.

For a complete R6 puck, print one P021 plate, one [P014 two-color bezel](bambu/P014-Pinstripe.3mf), one [P020 twist-lock lid](bambu/P020-lid.3mf) and one [power slider](puck_slider.stl). The [plain lid STL](P020-lid.stl) and [two aligned bezel meshes](components/) are included for other slicers.

Regenerate the plate from the repository root with `cad run hardware/case/puck_plate_p021.py`.
