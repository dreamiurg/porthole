Games for your round screen

Put a game on a Waveshare ESP32-S3 2.1-inch round touchscreen straight from this page. You don't need to install anything.

How to install

  1. Open this page on a computer in Chrome or Edge. Phones, Safari and Firefox can't talk to the board.
  2. Plug the board into the computer with a USB-C cable.
  3. Press Install under the game you want, pick the board in the list that pops up, and wait for it to finish (about a minute).
Updating a game you already have keeps your saved progress. Leave Erase device unticked when the installer asks. Switching to a different game starts it fresh.

Need a board? It's the Waveshare ESP32-S3-Touch-LCD-2.1, about $45, from Amazon or Waveshare. Get the flat 2.1-inch version: the round boards in other sizes won't work.

If something doesn't work

If the board doesn't show up in the list, try another USB-C cable: some cables only charge. Close any other program that might be using the board, then reload this page.

If the install stops halfway, press Install again. Nothing on the board can break; it just gets written again.

How this started

It started with a small MakerWorld project by MatixYo: a plane radar on a tiny round screen. I built one with my kids and showed them how to change it with Claude Code. Then we bought this bigger round screen and made a couple of games for it in one sitting. The kids loved them, and so did our friends' kids, so here they are. If you like to tinker, have fun with it.

Made with ESP Web Tools. Source code: porthole on GitHub.
