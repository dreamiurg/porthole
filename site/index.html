The boardПлата

Every game here runs on one board, and only this one is supported: the Waveshare ESP32-S3-Touch-LCD-2.1, the version with the flat 2.1-inch round screen. It's a round touchscreen with a small computer behind it. In a 3D-printed case it becomes a pocket gadget with no buttons at all.Усі ігри тут працюють на одній платі, і підтримується лише вона: Waveshare ESP32-S3-Touch-LCD-2.1, версія з пласким круглим екраном 2,1 дюйма. Це круглий сенсорний екран із маленьким комп’ютером позаду. У надрукованому на 3D-принтері корпусі він стає кишеньковою іграшкою зовсім без кнопок.

How to installЯк записати гру на плату

  1. Open this page on a computer in Chrome or Edge. Phones, Safari and Firefox can't talk to the board.Відкрийте цю сторінку на комп’ютері в Chrome або Edge. Телефони, Safari і Firefox не вміють працювати з платою.
  2. Plug the board into the computer with a USB-C cable.Під’єднайте плату до комп’ютера кабелем USB-C.
  3. Press Install under the game you want, pick the board in the list that pops up, and wait for it to finish (about a minute).Натисніть Install під потрібною грою, виберіть плату у списку, що з’явиться, і зачекайте, поки запис закінчиться (близько хвилини).

Updating a game you already have keeps your saved progress. Leave Erase device unticked when the installer asks. Switching to a different game starts it fresh.Оновлення гри, яка вже є на платі, зберігає прогрес. Не ставте позначку Erase device, коли установник спитає. Інша гра починається з нуля.

If the board doesn't show up in the list, try another USB-C cable: some cables only charge. Close any other program that might be using the board, then reload this page.Якщо плати немає у списку, спробуйте інший кабель USB-C: деякі кабелі лише заряджають. Закрийте інші програми, які можуть використовувати плату, і перезавантажте сторінку.

If the install stops halfway, press Install again. Nothing on the board can break; it just gets written again.Якщо запис зупинився на півдорозі, натисніть Install ще раз. Зламати плату неможливо, гра просто запишеться знову.

How this startedЯк усе почалося

It started with a small project on MakerWorld, ESP32 Plane Radar by MatixYo. A tiny ESP32 board and a 1.28-inch round screen pull live flight data from the internet and draw the planes overhead on a little radar. I built one with my kids, and then I showed them how to change it with Claude Code. They asked for changes and watched them show up on the little screen. I loved that.

Усе почалося з невеликого проєкту на MakerWorld, ESP32 Plane Radar від MatixYo. Крихітна плата ESP32 з круглим екраном 1,28 дюйма бере з інтернету дані про польоти й малює літаки над головою на маленькому радарі. Я зібрав такий із дітьми, а потім показав їм, як змінювати його за допомогою Claude Code. Вони просили зміни й дивилися, як ті з’являються на маленькому екрані. Мені це дуже сподобалося.

So we went one step further and bought a bigger round screen, this Waveshare board. In one sitting with Claude and Codex we had a couple of games running on it. My kids loved them so much that I shared them with friends, and their kids had a blast too. This page is where those games live now, and the repo is set up so anyone can add the next one.

Тож ми пішли далі й купили більший круглий екран, цю плату Waveshare. За один підхід із Claude і Codex на ній уже працювали кілька ігор. Моїм дітям вони так сподобалися, що я поділився ними з друзями, і їхні діти теж були в захваті. Тепер ці ігри живуть тут, а репозиторій налаштований так, щоб будь-хто міг додати наступну.

If you like to tinker and have about $45 for a board, or a spare one lying in a drawer, have fun with it. Enjoy the new era of tinkering.Якщо любите майструвати і маєте близько $45 на плату або зайву в шухляді, розважайтеся. Насолоджуйтеся новою ерою майстрування.

Different board? Fork itІнша плата? Форкніть

This is a side project, and I only support the board on my desk. I'm not porting the games myself, so hack away: point Claude Code or Codex at the repo and ask it to adapt the code to your hardware. Most of the hardware code sits in each game's board.cpp; a screen of another size or shape also means redoing the layouts. Got one working? Send a pull request, or just ask me a question.Це побічний проєкт, і я підтримую лише плату, що лежить у мене на столі. Сам я ігри не переноситиму, тож експериментуйте: попросіть Claude Code чи Codex адаптувати код із репозиторію під ваше залізо. Більшість коду для заліза лежить у board.cpp кожної гри; екран іншого розміру чи форми потребує нових макетів. Запустили? Надішліть pull request або просто поставте мені питання.
