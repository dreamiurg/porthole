---
name: new-story
description: Paw Street (apps/paw-street). Use when writing a new story (Book entry) or spelling-word (WordClue entry) batch. Covers the reading-level mapping, the real fit check the content has to pass, and the checker to run before finishing.
---

1. Reading level by age (`apps/paw-street/src/game/pet.cpp`'s `levelRange`): age <= 6 -> level 1 only; age 7 -> levels 1-2; age 8 -> levels 2-3; age >= 9 -> level 3 only. Write to the level you were asked for.
2. The real gate is pixel fit, not a character count: `apps/paw-street/tools/check_content.py` renders every string through the actual 8x8 proportional font and word-wraps it into the exact box the game draws it in — `page` 122px wide x 7-8 lines, `title` 108px x 2 lines, `question` 116px x 2-3 lines, `answer` 102px x 2 lines, `clue` 118px x 3 lines (line budgets shift slightly with how many lines the title itself wraps to). As a rough drafting budget before you run the checker: a page usually fits in ~130 characters, a title in ~16, a question in ~55, an answer in ~18 — but these are heuristics, not the rule; the checker's word-wrap is what actually decides.
3. Other limits the checker enforces: 3-11 pages per story, 2-3 answers, `correct` index in range, title and word uniqueness (no duplicates across the whole content set), spelling words uppercase and 3-9 characters, and 7-bit ASCII only everywhere (no curly quotes, no em/en dashes, no accented letters).
4. Beyond what the checker measures: the comprehension question must require connecting at least two pages, not restate one page verbatim, and the `correct` answer index should vary across a batch — check the existing distribution before defaulting to index 0. The checker won't catch either of these; you're the check.
5. Append (never edit or remove) a `Book{...}` entry to `BOOKS[]` in `apps/paw-street/src/game/content.h`, or to `apps/paw-street/src/game/content_level3_books.h` for level 3; append a `WordClue{...}` entry to `WORDS[]` in `content.h`, or to `apps/paw-street/src/game/content_level3_words.h` for the longer level-3 word list. `content.h` includes both level-3 files via `#if __has_include(...)` — the guard string must match the filename exactly.
6. Run `python3 apps/paw-street/tools/check_content.py` before finishing. It prints a one-line summary (`content: N stories, M words, K problems`) followed by one line per problem with a file:line and the reason. Fix every problem it reports; 0 problems is the bar, not "fewer than before."
7. Run `make -C apps/paw-street test` — a build failure here usually means a stray non-ASCII character or an unescaped `"` in a page or answer string that `check_content.py` didn't catch (it inspects the source text, not the compiled binary).
